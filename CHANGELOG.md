# История изменений

## 0.4.1

- Отпечаток TLS по умолчанию `firefox` вместо `chrome`: у части российских операторов соединения с отпечатком chrome обрываются через несколько секунд, с firefox работают. Для существующих серверов меняется в параметрах сервера.

## 0.4.0

- Цепочка из любого числа серверов с выбором выходного: в панели блок «Собрать цепочку» (вход, промежуточные серверы по порядку, выход), в консоли `lerk-vpn chain add s1 s2 s3 ... sN`.

## 0.3.0

- Новый дизайн панели: боковое меню с иконками, мягкие карточки, светлая и тёмная темы, нижняя навигация на телефоне, обновлённая страница входа.
- Прямой доступ без каскада: конфиг для Happ сразу на одном сервере, все параметры сервера и маршрутизация работают так же.
- Переименование клиента (ссылка подписки не меняется), каскада (название и имя), сервера (имя и страна); удаление сервера вместе с каскадами.
- Исправлены слипающиеся кнопки и блоки, цвета нативных элементов под тему, версия статики в адресе.

## 0.2.0

- Веб-панель: пульс, клиенты, серверы и каскады, конфиги Happ, маршрутизация, настройки, журнал действий.
- Добавление сервера по IP, логину и паролю; несколько серверов 1 и один сервер 2.
- Конфиги для Happ: подписка, deeplink, QR, заголовки профиля.
- Российский трафик напрямую по умолчанию: `.ru`, `.su`, `.рф`, `geoip:ru`, `geosite:category-ru`, российские сервисы; свои правила, каталог тегов, проверка домена и IP.
- Параметры сервера: порт Xray и SSH, SNI, fingerprint, flow, mux, swap, торренты, файрвол.
- Статистика трафика через API Xray, периоды со сравнением.
- Обновление панели кнопкой с проверкой и автооткатом.
- Установка одной командой (`install.sh`).

## 0.1.0

- Консольный движок: описание серверов и цепочек в одном файле, установка и настройка Xray, выпуск ключей и ссылок, сквозная проверка, подписки.
